# UI research notes

Written before the redesign of the booking app (October 2026). One note per
area. Each follows the same shape: who uses this screen and for what; the
products that solve the same job best and what they do, with specifics; the
principles that make them work; a critique of our current screen; concrete
recommendations for ours (layout, hierarchy, sizes, colour, interactions);
sources.

Context for every note: the app replaces a Gmail + Google Sheet + Excel
workflow for group bookings at a recreation park. The main user is an
operator who works in it all day and must be productive on day one with
little training. The stack is React + Tailwind + shadcn/ui; the brand is a
monochrome logo. The owner's verdict on the first build: correct information,
undigestible presentation — too dense, no colour as meaning, small type,
too many things per screen.
