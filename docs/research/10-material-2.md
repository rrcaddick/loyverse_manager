# 10 · Material Design 2: the colour system the owner meant

Everything before this note (research 07, 08, 09) built on Material 3's
seed-derived tonal palettes. The owner meant Material Design 2, the 2014
palette with its nineteen named swatches, which is what materialpalette.com
shows. The two are different systems; this note is the contract now.

## The system

A theme is **two swatches**: a primary and an accent, as on
materialpalette.com.

| Role | Light | Dark (Material's 2018 dark theme) |
| --- | --- | --- |
| primary (app bar, buttons, active tab and drawer item, links) | swatch 500; 700 dark variant, 100 light variant | swatch 200, dark text |
| accent (count badges, dots, FAB) | other swatch's A200 | the same A200 |
| text | #212121 / #757575 / #9e9e9e (87 / 60 / 38 % black) | white at 87 / 60 / 38 % |
| background, cards | Grey 50 canvas, white cards at 1 dp | #121212 canvas, surfaces lightened by the white overlay for their dp (1 dp 5 %, 4 dp 9 %, 8 dp 12 %, 16 dp 15 %, 24 dp 16 %) |
| dividers | 12 % black | 12 % white |
| hover, selected row | Grey 200, Grey 100 | white 8 %, 12 % |
| drawer | white at 16 dp; active item primary 12 % tint with primary text | 16 dp surface |
| app bar | primary 500 at 4 dp, on-primary text | 4 dp surface |
| error | #b00020 | #cf6679 |
| meaning (green, amber, red, blue) | swatch 100 fill, ink text, 600 dot | swatch 200 text and dot on a 20 % tint |
| elevation | the dp shadows: 1 cards, 2 raised buttons, 4 app bar, 8 menus, 16 drawer, 24 dialogs | the same shadows plus the overlays |
| shape | 4 px corners; chips and badges round | same |
| type | buttons and tabs in uppercase medium | same |

Text on a colour is white or 87 % black, whichever reads better, which is
how the spec's own table falls out (white on Indigo 500, black on Cyan 500).

## Where it lives

- `frontend/src/styles/m2.mjs`: the swatch table, `tokensFor(pair, mode)`,
  the dark overlays, the dp shadows and the materialpalette summary.
- `frontend/src/lib/appearance.ts`: applies the tokens for the user's pair
  inline on `<html>`; `index.html` does the same before the first paint;
  `tokens.css` (generated by `scripts/gen-m2-tokens.mjs`) holds the Indigo +
  Pink defaults.
- Settings › Appearance is the picker: primary grid, accent grid, the
  preview card and the eight palette cells.
- `scripts/check-palette.mjs` measures every primary × accent pair in both
  modes (10 944 checks) at Material's own bars: 4.5:1 for text, 3:1 for
  button and badge labels, and visible hover and selection.

## What was removed on purpose

The owner asked for the full Material 2 philosophy first, without his
earlier adjustments, so these are gone and can return in a second pass if
wanted: the banded surface ladder, zebra rows, the 50 % primary hover, the
primary-filled table head, doubled separators, the hand-picked highlight
hues, the ink button for Graphite.
