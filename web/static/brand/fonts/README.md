# Bundled fonts

`InterVariable.ttf` — Inter 4.1 variable font (weights 100–900), unmodified,
from the official release at https://github.com/rsms/inter/releases/tag/v4.1.
Licensed under the SIL Open Font License 1.1 (`LICENSE-Inter-OFL.txt`).

Used by the PDF documents (`web/templates/documents/document.css`) through a
`file://` `@font-face` so rendering does not depend on system fonts.
